## TODO.md

The `TODO.md` file holds the work items for this project.

- Item format: `- [ ] T### YYYY-MM-DD: description. Tags: @tag @tag`.
  An optional `Status: doing.` or `Status: blocked, reason.` follows the tags.
- You may add an item. Give it the next free ID and today's date.
- You may set an item's status to doing or blocked.
- Check the box only when every scenario in the item's tags passes.
- Move a checked item to the Done section. Remove its status.
- Do not delete an item, change its description, or change its tags.
  Ask the owner instead.
- Behavior is defined by the feature files. When an item and a feature file
  disagree, the feature file wins. Report the conflict to the owner.
